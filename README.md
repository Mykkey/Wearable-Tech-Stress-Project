# Wearable-Tech-Stress-Project

## CT4101 Machine Learning Portfolio Project

A multi-class classification project that asks "how effectively can different machine learning models predict a person's daily stress level (Low, Medium, High) from lifestyle habits and smartwatch-style measurements?"

The aim of the project is to demonstrate a sound, leakage-free process. The following will be involved: data auditing, pipelines, fair model comparison, error analysis, responsible ML reflection.
